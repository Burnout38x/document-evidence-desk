# Evidence Desk integration contract
React/Vite SPA with native Vercel Node API. ESM JavaScript, Node >=22. Root owns UI/build/docs/deployment. No keys required for real local evidence search; do not label local retrieval as generated AI.

src/data/documents.js exports documents array: {id,title,topic,url,updated,summary,passages:[{id,heading,text}]}. Curated paraphrases, clearly marked as reading notes, not direct quotations. Public technical docs focused on reliable web apps: HTTP caching, HTTP retry/idempotency, web accessibility, browser fetch errors, server secrets. Source attribution recorded. Prefer 5-6 sources with 2-3 short passages each.
src/lib/retrieval.js exports searchDocuments(question, {documentIds}={}) -> {status:'found'|'insufficient',results:[{id,documentId,documentTitle,heading,text,url,score}], terms: string[]}. Max 4 results. Meaningful relevance threshold; no fake probability. Optional documentIds restricts corpus. Deterministic token/keyword ranking is acceptable, disclose it; no embeddings claim.
src/data/evaluation.json generated by tests/evaluate.js -> {generatedAt,method,total,passed,metrics:{retrievalHitRate,abstentionAccuracy},cases:[{question,expected,passed,actual}]}. Rate metrics as 0..1, test actual retrieval, separate development fixture coverage vs general quality.
api/answer.js POST {question,documentIds?}. Returns {mode:'ai',answer,citations:[passage ID],...} or JSON {error,code} HTTP503 if absent config. Never accept client passages. API independently retrieves. GET returns {available:boolean} with no secret/config values. UI calls GET then offers AI only if available, otherwise only local evidence search. API integrates OpenAI REST via server fetch, validates cited IDs, does not stream. Agent selects safe model/current pricing from primary docs; cap prompt/output tokens, rate-limit and enforce lifetime <=$5 through durable atomic Redis precharge, no auto-reset. Missing durable budget store or allowance fails closed. Paid integration stays off by default. Avoid exposing keys/client input in logs. Error content user-safe.
